# Verbes Français

Persoenlicher Franzoesisch-Verbtrainer fuer Android (Java, Room, TTS).

## Starten
1. Ordner in Android Studio ueber File > Open oeffnen.
2. Gradle-Synchronisierung abwarten.
3. App starten.
4. JSON-Datei importieren: app/src/main/assets/verbes_core_01.json

## Funktionen
- Verb-Drill mit 6 Zeiten
- Spaced Repetition
- Beispielsaetze und Kontextuebungen
- Vorlesen auf Franzoesisch, auch langsam
- Fehler-Modus
- Statistik
- Tagesziel und Streak
- JSON-Import
- Backup exportieren und wiederherstellen

## Hinweis
Das Projekt enthaelt keine Gradle-Wrapper-JAR. Android Studio kann den Wrapper beim ersten Oeffnen einrichten.
